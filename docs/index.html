Ghost Shell

A haunted terminal. Gemma whispers from localhost after your commands, and keeps an ofrenda for everything you delete.

$ git branch -D experiment

🪦 experiment
A branch cut down before it flowered.

$ make test

👻 The build failed. Something in the walls is pleased.

$ ghost seance "what did I delete?"

👻 You buried experiment. The house still knows its name.

Install

git clone https://github.com//ghost-shell.git
cd ghost-shell
./install.sh

Then open a new shell. The rc file gains one line: source ~/.ghost-shell/ghost.sh
